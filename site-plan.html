Site Plan

Smart Forex Trading Hub

An educational website plan for beginner and intermediate Forex traders.

Site Name

Smart Forex Trading Hub - This name was selected because it communicates the focus on intelligent Forex education, trading guidance, and a community-style learning hub for beginning and intermediate traders.

Optional domain idea: smartforexhub.org

Site Purpose

The site will provide beginner and intermediate Forex traders with easy-to-follow educational content, practical trading strategies, risk management advice, trading psychology guidance, calculators and tools, and resources to build confidence and trading knowledge.

  • Explain Forex basics and trading terminology.
  • Show strategy examples and step-by-step guides.
  • Support users with trading tools, glossaries, and external resources.
  • Offer contact and feedback options to improve the learning experience.

Scenarios

  1. "How do I understand currency pairs, pips, and leverage before placing my first Forex trade?"
  2. "Which trading strategy is best for a new trader learning trend-following and breakout techniques?"
  3. "Where can I find a simple risk management plan and glossary of Forex terms?"

Color Scheme

The selected color scheme reflects a calm but confident financial education brand.

  • #0B3D91 - Deep navy blue for headings, navigation, and strong section accents.
  • #F5B841 - Warm gold for highlights, buttons, links, and call-to-action accents.
  • #F2F5F9 - Soft light background for page sections.
  • #1F2937 - Dark charcoal for body text, labels, and wireframe lines.

Typography

The site will use modern web fonts to support readability and clear hierarchy.

  • Inter - Used for headings, section titles, and the site brand name.
  • Roboto - Used for body text, paragraphs, list items, and form content.

Wireframe

These outlines represent the homepage layout for small and larger screens. The wireframe focuses on content structure, navigation, and responsive layout.

Mobile / Small Screen

Header / Logo + Menu
Hero section with introduction and featured content
Quick links: Basics, Strategies, Tools
Highlighted articles and calculators
Contact and footer links

Desktop / Larger Screen

Header / Logo + Navigation
Hero with overview and call-to-action
Sidebar links or featured tools
Main topics: Basics, Strategies, Resources
Footer with contact info and validation notes

Testing

Self-check will cover:

  • HTML validation with W3C Markup Validator
  • Accessibility evaluation using WAVE
  • Best practices, SEO, and performance review with Lighthouse
  • Color contrast checking using WebAIM Contrast Checker
